# Python Skill

## Purpose
Write reliable, readable, and maintainable Python code.

## Guidelines
- Use clear names, type hints, and docstrings.
- Prefer small, reusable functions.
- Validate external input.
- Handle exceptions explicitly.
- Use pathlib for file paths.
- Load secrets using python-dotenv.
- Never hardcode API keys.
- Include runnable examples and dependencies.
- Explain errors and provide minimal reproducible fixes.
