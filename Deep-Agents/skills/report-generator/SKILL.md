# Report Generator Skill

## Purpose
Create clear, evidence-based technical reports.

## Report structure
1. Title and date
2. Executive summary
3. Research question and scope
4. Methodology
5. Findings and supporting evidence
6. Source URLs
7. Recommendations
8. Limitations and uncertainties
9. Conclusion

## Rules
- Never invent citations or statistics.
- Link sources used to support factual claims.
- Distinguish facts, estimates, and recommendations.
- Identify conflicting evidence.
- Explain assumptions and missing information.
- Keep reports clear and actionable.
